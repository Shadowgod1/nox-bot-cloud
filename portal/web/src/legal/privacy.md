## 5. Передача третьим лицам

Данные передаются только в объёме, необходимом для работы сервиса:

- **Поставщики моделей искусственного интеллекта** (Anthropic, OpenAI, Google) — фрагменты переписки и сведения о компании Заказчика для формирования ответа бота. Поставщики обрабатывают данные за пределами Республики Казахстан (трансграничная передача) по своим условиям для бизнес-клиентов; Исполнитель передаёт только данные, нужные для ответа.
- **WhatsApp (Meta)** — отправка и получение сообщений на номер Заказчика.
- **Kaspi, банки** — приём оплаты.
- **Почтовый сервис хостинга** — отправка писем (коды подтверждения, счета, уведомления).
- Государственные органы — только по законному требованию.

Исполнитель не продаёт данные и не использует переписку клиентов Заказчика для рекламы.
